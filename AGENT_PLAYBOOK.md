# Agent Playbook

1. Confirm the engineering question and decision quantity.
2. Validate reaction and experiment manifests against schemas.
3. Confirm units, stoichiometry, phases, feeds, pressure, and thermal properties.
4. Run tests and reproduce the synthetic baseline without model changes.
5. Create a new folder under projects/ or case_studies/ for uploaded data.
6. Calibrate only on the declared calibration split.
7. Report identifiability, parameter covariance, correlations, and practical bounds.
8. Evaluate on held-out data and report residual patterns, not only aggregate error.
9. Run tolerance checks, conservation checks, uncertainty propagation, and sensitivity.
10. Optimize only within reviewed constraints. Label outputs as hypotheses.
11. Report assumptions, solver diagnostics, validation range, and safety limitations.
