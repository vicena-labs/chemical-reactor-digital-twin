# Release checklist

- [ ] Tests and analytical checks pass.
- [ ] README matches executable capabilities.
- [ ] No secrets, private data, proprietary kinetics, or unsafe procedures.
- [ ] Schemas validate examples.
- [ ] Calibration and validation splits are distinct.
- [ ] Solver diagnostics and tolerance checks are recorded.
- [ ] One-page PNG and PDF are regenerated from repository results.
- [ ] No em dash characters appear in repository text.
- [ ] License, VERSION, CITATION.cff, changelog, description, and topics agree.
- [ ] Clone URL, default branch, important paths, and detected MIT license are verified after publication.
