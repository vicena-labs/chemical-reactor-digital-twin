# Method and software references

The bundled reaction network is synthetic and is not taken from a chemical publication.

- SciPy integration and nonlinear least-squares APIs provide the numerical implementation. Record the installed SciPy version in every reference run: https://scipy.org/
- NumPy provides array and linear-algebra operations: https://numpy.org/
- JSON Schema Draft 2020-12 defines the manifest validation vocabulary: https://json-schema.org/draft/2020-12

For adapted projects, add primary references for every kinetic law, equilibrium relation, thermodynamic property, transport correlation, spectroscopy calibration, experimental dataset, and safety limit. A software reference cannot substitute for chemistry-specific provenance.
